Начнём с одного настоящего рабочего потока:
Manager создаёт компанию → открывает её → видит площадку → видит оборудование → создаёт заявку.

А затем:
Leader видит заявку → назначает Engineer.

А затем:
Engineer открывает свою заявку → меняет статус → пишет комментарий.
